# Прокси Businessmania → Gemini (Cloudflare Workers)

Ключ Gemini и промпты живут **только здесь**. Игра шлёт номер проблемы, язык, текст игрока и ошибки цикла;
рубрики и эталоны прокси берёт из `rubrics.json` (в игре их нет).

## Деплой

```bash
cd proxy
npm install
npx wrangler secret put GEMINI_API_KEY      # ключ - только секретом
npx wrangler deploy
```

Настройки — `wrangler.toml` (`[vars]`): `ALLOWED_ORIGINS`, `GEMINI_MODEL`, `RATE_LIMIT_PER_MIN`, `DAILY_CAP`,
`UPSTREAM_TIMEOUT_MS`. Для счётчиков, переживающих перезапуск изолята, подключить KV `LIMITS` (инструкция в файле);
без KV лимиты считаются в памяти изолята (best effort). **Бюджет в Google Cloud только шлёт уведомления,
стопор — `DAILY_CAP` здесь.**

Модель `GEMINI_MODEL` по умолчанию `gemini-2.5-flash` — проверьте актуальное имя Flash-модели перед боевым запуском.

## Эндпоинты

`GET /ping` — эхо: `{ok, origin, allowed, time}`. Отвечает любому Origin и разрешает его читать — по нему из билда на
itch.io узнаём точный домен источника и проверяем CORS (день 2 плана). Из игры: `DirectorClient.ping()`.

`POST /evaluate` — только для разрешённых Origin.

```json
{ "problem_id": "credit_1", "lang": "ru", "text": "…до 150 символов…",
  "mistakes": [ { "question": "", "player_answer": "", "correct_answer": "", "explanation": "" } ] }
```

Ответ 200: `{ "score": 0-3, "verdict": "", "missing": "", "better": "" }` (порядок полей — как в схеме Gemini).
Пустой `text` → `score: 0` без обращения к модели. Ошибки: 400 (плохой ввод), 403 (Origin), 413, 429
(`rate_limited` / `daily_cap`), 502 (модель/таймаут), 503 (нет ключа). Игра на любую ошибку уходит в эталонный ответ.

## Защита

Текст игрока идёт в `<player_answer>` как данные, системный промпт велит не выполнять инструкции внутри; выход модели
ограничен схемой и ещё раз проверяется (`score` — целое 0–3). Лимиты: длина текста, таймаут 7 с, запросы с IP в минуту,
суточный потолок, список Origin. Origin проверяет только браузер — это не авторизация, реальные ограничители расходов —
лимиты и суточный потолок.

## Проверка (как делалось)

Воркер прогонялся локально с подменой `fetch` на Gemini (валидация, CORS, лимиты, таймаут, неверный вывод модели),
а Godot-клиент — против него по HTTP (успех, недоступный адрес, медленный ответ → фолбэк через 8 с).
Живой вызов Gemini с настоящим ключом **не проверялся** — нужен ключ.
