# Передача проекта Internity (Businessmania)

Для нового участника, в том числе если он работает через ИИ-ассистента (Claude Code и т.п.).

## 1. С чего начать
0. Репозиторий: `https://github.com/TimDev7/business-mania` (ветка `main`). Новому участнику выдать доступ (Settings -> Collaborators) или передать репозиторий; клонировать: `git clone git@github.com:TimDev7/business-mania.git`. Собранные билды в git не хранятся (`export/` в `.gitignore`), их каждый собирает сам.
1. Godot **4.7** (та же версия, что в `project.godot`), Node.js (для прокси), аккаунты: itch.io, Cloudflare, Google AI Studio (ключ Gemini).
2. Клонировать репозиторий, открыть в Godot, дать редактору **полностью** завершить первый импорт (не закрывать по таймауту: иначе `.godot/` кэш остаётся битым и автозагрузки резолвятся в `Nil`).
3. Если работаете с ИИ: открыть папку проекта в Claude Code. Он сам прочитает `CLAUDE.md` - там архитектура и жёсткие правила. Это главный файл для ИИ, держите его актуальным.

## 3. Правила работы (важное из CLAUDE.md)
- **Сцены `.tscn`, `export_presets.cfg` и настройки экспорта правятся только в редакторе**, пока он открыт, иначе он затрёт ручные правки. ИИ пишет скрипты, данные, схемы нод; ноды собирает человек.
- Любой новый текст добавляется **во всех трёх языках** в одном ключе `{"ru","kk","en"}`, число `%s/%d` одинаково. Статичные надписи в сцене помечаются `metadata/tr_key`.
- Числа и правила игры - в JSON/`game/logic`, не в скриптах сцен. Скрипт сцены не больше ~200 строк.
- Тесты пишутся только для `template/`, не для кода игры.
- Коммит и пуш - только по явному решению человека.
- План и журнал сессий: Notion, страница «Businessmania» -> «План финиша (с 18.10)». Доступ нужно выдать новому участнику. Для ИИ подключить Notion MCP (`claude mcp add --transport http notion https://mcp.notion.com/mcp --scope user`, затем `/mcp` для авторизации).

## 4. Секреты (не в репозитории, передать отдельно)
- **Ключ Gemini** лежит только в секрете воркера (`wrangler secret put GEMINI_API_KEY`). В игре и в git его нет.
- Аккаунт Cloudflare: воркер `businessmania-proxy`. Новому участнику нужен доступ к аккаунту или он разворачивает свой воркер и меняет `proxy_url` в `game/data/config.json`.
- `ALLOWED_ORIGINS` в `proxy/wrangler.toml` должен включать домен страницы (сейчас itch.io и `*.itch.zone`). Если игра переедет на другой домен, добавить его и задеплоить воркер.
- Не коммитить `.env`, ключи, `export_credentials.cfg`.

## 5. Выпуск новой версии
1. Правки текстов/кода -> прогнать игру целиком в редакторе (путь в `docs/export_checklist.md`, раздел 5), во всех трёх языках.
2. Менялся `proxy/` -> `cd proxy`, `npx wrangler deploy`.
3. Редактор: Project -> Export -> Web, настройки по `docs/export_checklist.md` (PWA выкл, Head Include для iPhone, Export With Debug выкл), путь `export/web/index.html`.
4. Заархивировать содержимое `export/web/` так, чтобы `index.html` лежал **в корне** zip.
5. itch.io: загрузить zip поверх старого, галка «played in the browser», viewport 540x1200.
6. Открыть живую страницу с телефона и проверить: титул, смену языка, ответ куратора.

## 6. Известные открытые вопросы
- Казахские тексты написаны ИИ, нужна вычитка носителем (терминология и вопросы квиза).
- Gemini на бесплатном ключе отвечает 6-12 с и иногда падает; при ошибке игра показывает эталонный ответ. Решение про платный ключ не принято.
- Иконки, портрет куратора и текстуры полос - SVG-заглушки в `assets/textures/`, заменяются файлами с тем же именем.
- iPhone: зум на поле куратора лечится Head Include в пресете экспорта, нужна проверка на реальном устройстве.
- Язык меняется только на титуле (или перезагрузкой страницы).

## 7. Как ставить задачи ИИ
Хорошо работает формулировка «что сломалось или что нужно + где видно (экран/язык)». ИИ не может запустить игру, поэтому **визуальную проверку всегда делает человек** и присылает скриншот или текст ошибки из Output. После крупной правки просите ИИ обновить `CLAUDE.md` и этот файл, чтобы следующий чат знал новые правила.
