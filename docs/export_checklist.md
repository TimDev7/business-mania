# Чек-лист экспорта Internity (Web, itch.io)

Настройки экспорта и проекта правятся **только в редакторе** (правило проекта: `export_presets.cfg` руками не трогать).

## 1. Настройки проекта (Project → Project Settings)
- [ ] Application → Config → **Name** = `Internity` (из него берётся заголовок вкладки браузера; сейчас там `CoreTemplate`).
- [ ] Application → Config → **Icon** = логотип (из него делается favicon страницы; сейчас стоит `assets/textures/icon.png`).

## 2. Пресет Web (Project → Export → Web)
- [ ] **Exclude Filters:** `res://test/*, res://addons/gut/*, res://tools/*, res://Export/*, res://export/*, *.aseprite`
      (тесты и GUT не нужны в билде; `proxy/` и `export/` уже спрятаны файлами `.gdignore`).
- [ ] Variant → **Thread Support = выкл**, Extensions Support = выкл (для itch без особых заголовков).
- [ ] HTML → **Experimental Virtual Keyboard = вкл** (иначе на телефоне нет клавиатуры в поле куратора).
- [ ] HTML → Canvas Resize Policy = Adaptive.
- [ ] **HTML → Head Include** (лечит зум на iPhone: Godot создаёт скрытое поле для клавиатуры без размера шрифта, а iOS Safari приближает страницу, если шрифт поля меньше 16 px, и обратно её не отпускает):
      ```html
      <style>
        input, textarea { font-size: 16px !important; }
        html, body, canvas { touch-action: manipulation; }
      </style>
      ```
- [ ] **Progressive Web App → Enabled = выкл.** PWA ставит service worker и кэш: гости могут видеть старую версию после обновления билда.
- [ ] Снять галку **Export With Debug** для финальной сборки.
- [ ] Export Path = `export/web/index.html`.

## 2а. Языки (ru / kk / en)
- [ ] Шрифт `assets/font/ptsans/PT_Sans-Web-Regular.ttf` лежит в проекте вместе с `OFL.txt` (лицензия требует сохранить текст рядом со шрифтом).
- [ ] В режиме **kk** нет пустых квадратов вместо букв ә ғ қ ң ө ұ ү һ і (проверить на титуле, в вступлении, в вопросах, в окне куратора). Если есть, в Output будет предупреждение `UiStyle: в шрифте ... нет казахских букв`.
- [ ] Кнопка языка на титуле (слева внизу) переключает ru -> kk -> en, надписи титула обновляются сразу; после «Начать стажировку» вся игра на выбранном языке.
- [ ] Выбор языка запоминается (localStorage): при следующем открытии страницы язык тот же. У гостя на стенде язык предыдущего гостя можно сменить только перезагрузкой страницы (кнопка «Новый день» остаётся внутри игры).
- [ ] Казахские тексты вычитаны носителем: `game/data/ui_strings.json`, `story.json`, `director.json`, `minigames.json`, `questions.json` (ключ `kk`).

## 3. Перед сборкой (данные)
- [x] `game/data/config.json`: `cycle_count` = 2, `show_error_code` = **false**, `proxy_url` = адрес воркера.
- [ ] Воркер задеплоен последней версией (`cd proxy`, `npx wrangler deploy`): в нём промпт куратора Армана и таймаут 11 с.
- [ ] Ключ Gemini: решить про платный (быстрее и стабильнее, запросы не уходят на обучение).
- [ ] В `ALLOWED_ORIGINS` воркера есть домен страницы (itch.io и `*.itch.zone`); проверено живым билдом.

## 4. Сборка и заливка
1. Export Project → папка `export/web/`.
2. В zip должен лежать `index.html` **в корне архива**, не внутри папки.
3. itch.io: тип Kind of project = **HTML**, галка **This file will be played in the browser**.
4. Viewport size = **540 × 1200** (вертикальный), включить **Mobile friendly** и **Fullscreen button**.
5. Страница сначала закрыта паролем/черновиком; открыть перед мероприятием.
6. Текст страницы - `docs/itch_page.md`.

## 5. Проверка перед мероприятием (прогнать целиком)
Путь: титул → вступление → день 1 (все три мини-игры и квиз, обучалка при первом появлении) → итог → куратор → разбор ошибок → магазин → день 2 → финал → «Новый день».

| Устройство | Что смотреть |
|---|---|
| ПК, Chrome | всё целиком, звук, кнопка AlmaU открывает сайт |
| Android, Chrome | вертикаль, тач, клавиатура в поле куратора, перетаскивание топпингов |
| iPhone, Safari | то же; блокировка ориентации не поддерживается (это нормально). **Обязательно:** тапнуть в поле ответа куратору - страница не должна приближаться, кнопка «Ответить» должна оставаться видимой; на итоге дня должна быть строка «Это ещё не конец» |
| Слабый интернет | куратор отвечает позже или уходит на запасной ответ, игра не зависает |

Быстрая проверка директора без игры: `cd proxy; node tools\eval_cases.mjs https://<воркер>.workers.dev`.

## 6. Известные особенности
- Директор на бесплатном ключе Gemini отвечает 6-12 с и иногда падает: срабатывает эталонный ответ (по задумке).
- Музыка стартует после нажатия «Начать стажировку» (браузер не включает звук без жеста).
- Иконки, портрет куратора и текстуры полос - заглушки в SVG (`assets/textures/*`), заменяются подменой файлов тем же именем.
